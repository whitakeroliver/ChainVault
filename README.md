# ChainVault

ChainVault utilizes a distributed key-value store to securely manage keys in real-time, facilitating transparent data encryption system operations.

ChainVault is built to be simple and practical, focusing on doing one thing well.

**Why ChainVault?**

- ChainVault utilizes a distributed key-value
- store to securely manage keys
- in real-time, facilitating transparent data

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/ChainVault.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure ChainVault, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
